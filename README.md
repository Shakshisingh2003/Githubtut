Personalized Learning Recommendation System

Project Overview

The Personalized Learning Recommendation System is a Machine Learning project that helps students by providing personalized learning recommendations based on their academic performance and learning data.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Machine Learning

Features

- Student performance analysis
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature importance analysis
- Machine Learning model evaluation
- Personalized learning recommendations

Project Files

- "personalized_learning.py" – Main Python program
- "student_performance.csv" – Dataset
- "feature_importance.csv" – Feature importance results
- "model_evaluation.csv" – Model evaluation results
- "learning_recommendations.csv" – Learning recommendations

How to Run

1. Install the required Python libraries.
2. Open the project in VS Code.
3. Run the Python file.
